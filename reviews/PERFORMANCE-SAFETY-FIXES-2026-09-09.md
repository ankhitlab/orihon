# Исправления по ревью от 2026-09-09

Внесены исправления всех 11 замечаний и архитектурных предложений исходного отчёта. Порядок: целостность данных и отмена → общий bulk/diff → частичная сцена → headless ИИ → remote/query/SSE → проверки.

## Контракты и оставшиеся ограничения

Подробности и миграция: [PERFORMANCE-OBJECT-MANAGER.md](../docs/PERFORMANCE-OBJECT-MANAGER.md).

Headless query ограничивает размер результата, но пока сканирует коллекцию; bbox — грубый фильтр по прямоугольникам. Обновление AI-коллекции сохраняет поверхностное копирование Map; глубокая сериализация всего набора больше не обязательна. SSE ограничивает очередь, но сериализация одного большого события создаёт временную строку. Чистота style/equals и стабильные ID — часть контракта. Эти ограничения отмечены явно, без обещания O(k) для всего кадра или транзакции.
